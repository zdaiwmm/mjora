# Photos Phases 1–3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for integration; use dispatching-parallel-agents only for disjoint domains with the frozen editor contract. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement all user-approved phases 1–3, then install and review the app in the dedicated simulator before acceptance.

**Architecture:** Native SwiftUI/UIKit/PhotoKit client; Immich-derived server atomic edit list. Independent UI and backend domains can proceed in parallel under the editor wire contract; root owns source-aware state and integration. Existing backup safety rules remain binding.

**Tech Stack:** Swift 6, iOS 26+, PhotoKit, CoreImage, XCTest, TypeScript/NestJS/Sharp/Vitest.

**Spec:** ../specs/2026-11-15-photos-phase123-design.md

## Global Constraints
- Implement phases 1–3 only; phase 4 planning goes into a new separate chat.
- Originals and verified backup receipts are independent of rendered edits; a derivative must never authorize device-original deletion.
- Same-device Apple Photos is the visual reference. Keep existing app architecture and source separation.
- Explicit capabilities gate enhanced server actions. No version-number guessing or silent uploads.
- Test isolated synthetic data only. No production deploy/push/main merge or physical-device update.
- All final evidence is fresh from the changed build; simulator UUID 75A1015C-96F9-4D6F-9913-064BC83F3085.

## Review Focus
- Account switch while retries/rendering are in flight: old account jobs cannot mutate the new session.
- Local full/limited/denied permission and unbacked assets: controls reflect actual ability and preserve originals.
- A successful request with a lost response: read back the complete intent, retain draft and avoid false rollback.
- Editing plus favorite/source/grid changes: no stale cache, pair receipt or viewer selection may reappear incorrectly.
- Interrupted transition, rotation, Reduced Motion and relaunch: consistent anchored position and persistent preferences.
