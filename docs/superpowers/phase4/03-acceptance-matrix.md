# 第四批验收矩阵（未来执行，当前全部未测）

日期：2026-11-15。本文定义验收，不是测试报告。仅文档静态检查可在本规划会话运行；媒体、服务端、数据库、模拟器和真机测试均须后续独立实施环境。

本版纳入二次审计与用户图片即时呈现要求，总计**122项**。新增I01–I18、U01–U18见第12–13节，G5的指标、前提和样本方法以 [增补规范](07-loading-and-interaction-spec.md) 第11节为准；以下原P01–P06继续覆盖编辑/影片性能，不能代替全App加载体验。

每个用例记录 `caseID / build / server capabilities / OS+device / accountScope / sourceRevision / editRevision / command / actual / evidence / status`。状态只能为 PASS、FAIL、NOT RUN、N/A（注明能力和原因）；未运行不能填 PASS。

## 1. 覆盖维度与夹具

| 维度 | 必须覆盖 |
|---|---|
| 来源 | 未备份本机、双方原件已验证配对、纯云端；配对未知/冲突是负向夹具 |
| 服务端 | 增强 feature 全开、仅部分子能力、旧 Immich/Gallery/Imora 兼容路线、probe失败、运行中撤销能力 |
| 权限 | PhotoKit全库/有限/拒绝；云端owner/edit/read-only/撤权；导出添加权限拒绝 |
| 网络 | 离线、Wi-Fi、未获准蜂窝、请求发送前断线、提交后丢响应、429、401/403、慢下载、事件丢失 |
| 生命周期 | 编辑器关闭/后台/强杀/重启、暂停屏障、token过期、登出换账号、LAN/WAN同服务器 |
| 媒体 | 有/无音轨、竖向transform、不同clean aperture、24/25/30/60fps与VFR、短片、长4K、Live原照与motion画幅不同、HDR/Log/空间/电影效果 |
| 界面 | 亮/暗、Reduced Motion、动态字体、VoiceOver真实操作、横竖屏、iPad布局；未验证平台不宣称等价 |

媒体夹具建议置于未来 `tests/phase4/`，每项有 manifest 与原件 SHA-256：

- `live-abcd`：四个具可辨识编号的运动帧＋独立高分辨率原照，源PTS包含非均匀间隔；另有带音轨和无音轨版本。
- `live-current-vs-original`：原始/当前照片与运动资源同时存在且字节不同；配对错误/一方缺失各一份。
- `video-orientation-vfr`：标记四角、非正方形、preferredTransform、可对齐音画脉冲，用于坐标与时序；源每帧PTS已知。
- `video-color-sdr`：统一色块、灰阶/肤色/高光暗部参考，源color metadata明确；HDR/Log另作为拒绝/显式转换夹具。
- `collections-metadata.json`：固定UTC时刻、capture wall-clock/offset、DST边界、粗粒度GPS、精度、visibility、logicalID；Native/Server消费同一组期望。
- `movies-manifest-v1.json`：15/30/60秒、60/90/120BPM、短素材、受限音乐、混合来源、缺失素材；外部图像不含真实个人信息。

不能为了完成验收把合成夹具导入用户真实图库。系统写回必须使用未来授权的专用测试库/设备，真实媒体写操作不在本次授权中。
