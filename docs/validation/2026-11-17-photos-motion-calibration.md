# 照片交互动效节奏校准（2026-11-17）

参照同机 iOS 27.2 系统「照片」，盘点 SwiftUI 显式/隐式动画、UIKit animator、手势释放、图片交接、系统转场及定时器。实现集中在 `Imora/DesignSystem/PhotosMotion.swift`，原生导航、菜单、分享面板和系统编辑器出入场继续使用系统动画。

## 参考采集

使用独立的 `Imora Native Photos Reference` 模拟器、专用合成照片库和 `PhotosMotionReferenceTests`。仅在参考系统 App 进程中记录 `CALayer` 接收的动画；记录器保存在本地 execution 目录，不编译进 Imora 或安装包。阶段时间戳、完整 AX、截图及原始 JSONL 一并保留。

| 系统照片场景 | 实际采集结果 | 应用处理 |
| --- | --- | --- |
| 图片打开 | 350ms，临界阻尼，单位质量刚度约 695.967 | 原 320ms 改为 350ms，同曲线 |
| 图片关闭 | 300ms，临界阻尼，单位质量刚度约 947.288 | 保留 300ms，集中定义 |
| 信息按钮展开/收起 | 约 505.824ms；mass=3、stiffness=1000、damping=500，系统钳制为临界阻尼 | 保留已有正确物理曲线，并作为自定义布局/释放回位的共同参考 |
| 详情工具栏显隐 | 200ms，ease-in-out | 同步 SwiftUI 控件与 UIKit 图片布局的时长及曲线 |
| 编辑器图片/工具交接 | 图片交接 300ms，预览内容淡变 250ms | 系统编辑出入场保持原生；工具面板采用 250ms，裁剪/旋转/撤销的空间变化使用布局弹簧 |

年/月/全部、网格密度等系统内容经过 Photos 自身的渲染管线，不能从这里的 CALayer 记录声称已取得每个私有动画的精确参数。这些自定义空间变化采用上表已实测的照片布局弹簧，再通过实际流程验证连续性；不是对私有实现逐帧等同的宣称。不同 iOS 版本及真机 60/120Hz 的帧间隔需要各自验证。 当前已连接的部署目标为 iOS 26.6.1；本轮没有测量其系统照片的逐帧参数。

## 调整范围

| 场景 | 调整 |
| --- | --- |
| 详情打开、关闭、打开中立即返回 | 使用场景参数，保持现有可中断生命周期及照片身份交接 |
| 拖动取消回位 | 原最短 140ms 改为约 506ms 的临界阻尼弹簧；减少动态效果保留短交接 |
| 年/月/全部、双指缩放释放、筛选重排 | 原 300/320ms 的独立动画统一为布局弹簧；手指跟随期间仍直接更新几何 |
| 底部导航、选择模式、精选集折叠 | 布局变化协调到同一物理节奏 |
| 底部图片条 | 手动翻页后的尺寸/中心恢复使用布局弹簧；直接拖动不附加缓动 |
| 编辑器 | 工具面板 250ms；比例、旋转、重置、撤销/重做的几何使用布局弹簧 |
| 搜索、人物、相簿选择及列表更新 | 移除分散的快速 snappy/smooth 覆盖，采用共享布局或控件动画 |
| 清理卡片 | 取消拖动回位及撤销使用布局弹簧，离场 300ms；手势识别和决策逻辑不变 |
| 图片/行移除 | 120/200ms 淡出协调为 300ms |
| 地图、卡片按压释放 | 空间变化使用布局弹簧 |
| 回忆播放 | 缩略图条居中使用布局弹簧，控件显隐 200ms；媒体时长、播放进度和自动换片淡变不变 |
| 分享准备提示、状态提示 | 自定义提示布局使用共享节奏；减少动态效果下移除缩放 |

盘点后保留：滚动指示器的即时显隐、真实媒体/上传进度插值、内容相同的 80/100ms 图片交接、Live Photo 按住识别时间、手势速度和滚动减速模型、账户/PIN 反馈、折叠硬件适配。这些分别属于持续输入反馈、媒体时钟、无可见几何变化的交接，或没有系统照片对应流程的场景，不能简单按倍率延长。

## 实际 API 差异与回归

在本次 SDK/runtime 上，`UISpringTimingParameters(duration: 0.35, bounce: 0)` 配合 animator 实际生成约 514ms、刚度约 322.273 的动画，不能用入参数值推断最终节奏。最终使用 duration/damping-ratio initializer，单元测试直接检查实际发出的 `CASpringAnimation` 与系统参考匹配。

新增回归还覆盖：更慢的缩放释放途中开始下一次缩放，旧 completion 不能清除新 overlay。两条原有年/月图片连续性测试从固定等待 500ms 改为有界等待实际交接完成，避免将新的正常时长误报为残留。
