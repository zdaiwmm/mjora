# Imora

## Register
Product: native iOS photo library and self-hosted photo/backup client.

## Users and purpose
People browse their device and private server photos, search, organize, edit and back up media. Daily browsing and safe media ownership are primary. The existing code and user-approved phases 1–3 define this context.

## Reference and personality
Apple Photos on the same iOS device is the explicit reference: familiar, photo-first, quiet and responsive. Preserve Imora account/server/backup affordances with clear source semantics. Use native system colors, SF Symbols, typography and glass only where the system uses it.

## Principles and anti-references
Photos carry the visual focus. Avoid repeated normal-state badges, decorative dashboards, duplicate navigation and unsupported placeholder controls. Original files and verified backup evidence remain distinct from edits.

## Accessibility
Use honest AX labels with the same semantic dates as visible labels. Honor Reduced Motion, dark appearance and appropriate touch targets. No fabricated frame-rate or real-device accessibility claims from screenshots.
